# MacOS `fn` to `Alt`

MacOS maps the Windows-equivalent `Alt` keybinding to the `⌥ Option` key and left the `fn` key unreadable to Windows virtual machines. This script maps the `fn` key to `Alt`, temporarily while it is running.

This is useful for Cloud Gaming, since many games use `Alt` as one of the useful keybindings. If we do not map the key, unfortunately, the location of MacOS's `⌥ Option` key in the keyboard is not flexible for me and I often end up in quite an awkward position.

To run the script, you need to clone this repository and then do `bash main.sh`. Keep the Terminal open to sustain the mapping.
